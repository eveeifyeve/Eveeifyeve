# Security Policy

We take the security of my projects seriously. If you find a security bug, please help us fix it by telling us responsibly.

## Reporting a Vulnerability

**Please do not open a public issue or discussion for security bugs.** 

Instead, please report it privately:
* Use [GitHub Private Vulnerability Reporting](https://github.com/) if it is enabled for this repository.
* Else Email me directly at: `security@eveeifyeve.dev`
    * PGP Key: `<TODO>`

Please include:
* A description of the bug and where it is.
* Steps to recreate or test the issue.
* Any impact or risk details you know.

## What to Expect

* We will reply within **48 hours** to let you know we received your report.
* We will work to verify the bug and create a fix.
* We ask that you keep the report private until we release a fix or make a public announcement.
